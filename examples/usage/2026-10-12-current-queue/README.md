# Observed tokens/timing during ongoing conversion

This is a read-only snapshot of existing native histories/receipts, not output from the new three-round benchmark. It includes retained conversion epochs and repairs. Whole-epoch coverage is partial: old failed calls and unbound usage exist. Known tokens are lower bounds on total consumption, never zero-filled failures or provider billing.

The source/program/model/contract/page identity is recorded for each group. Latest accepted producer windows are separate from whole final-attempt usage and all repairs; repeated reviews on the same numeric attempt are not collapsed into one final call. Reasoning is an output subset; cache reads are already included in a reported prompt total. MiniMax’s absent prompt-total/cache-write means known component sums are lower bounds.

Native wall time and reported model inference duration are separate from job/provider waits. Raw histories and compact debug transcripts remain private; this report contains numbers and source identities only. [Collector method](../../../docs/USAGE-AND-DEBUG.md).
