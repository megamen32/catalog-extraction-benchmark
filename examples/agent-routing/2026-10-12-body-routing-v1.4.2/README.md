На22 осталось два пропуска выбранных фактов. Один вызов Docling на111 завершился ошибкой импорта shared object при заданном ограничении виртуальной памяти; агент всё равно сохранил15/15 фактов через другие свидетельства. Этот отказ записан отдельно от качества документа.

Наблюдались12 успешных вызовов чтения canonical, raw не читался. Диапазоны API покрыли два файла до конца (gmft на38 и Docling на30), однако FastAgent сократил9 длинных ответов перед передачей модели. Без сокращения целиком предъявлен только gmft на38; на30 чтение сохранённого canonical через grep тоже было сокращено. Успешные диапазоны API не доказывают, что модель увидела весь файл. Он дополняет их прямыми таблицами и изображениями. Поэтому инструкция не является гарантией полного просмотра каждого артефакта; gmft был выбран на38 и дал вместе с агентом72/72, как и прежние варианты; его универсальное превосходство здесь не подтверждено. [Правила выбора](../../../../docs/TOOL-ROUTING.md) остаются основанными на видимых свойствах страницы и проверке оригинала.

Все14 точных выходных JSON и подробные данные по каждому случаю — рядом в [manifest.json](manifest.json). Транскриптов нет.
