# Catalog Vision Backend

[Catalog Vision Backend](https://github.com/megamen32/catalog-vision-backend) — наша закрытая адаптация существующего обработчика документов для работы с каталогами. Репозиторий остаётся приватным; исходный код не публикуется в этом бенчмарке. Доступ по запросу; планируем предоставлять бесплатно.

Для доступа напишите [владельцу в GitHub](https://github.com/megamen32), указав свой GitHub-логин. Без приглашения приватная ссылка может показывать 404; это не означает, что репозиторий удалён.

Компонент обрабатывает PDF, DOCX, XLSX и HTML, сохраняет происхождение данных и предоставляет интерфейс для использования агентом. Детерминированное чтение и модельный Vision-проход — отдельные режимы.

Публичный [catalog-to-json](https://github.com/megamen32/catalog-to-json) работает самостоятельно: FastAgent, AnyDoc, PDF-инструменты и Vision. Доступ к приватному репозиторию ему не требуется. Catalog Vision Backend пока не подключён в его коде и рассматривается отдельно.

## Название и происхождение результатов

В документации используется **Catalog Vision Backend**. Старое условное имя **Project X** и технические идентификаторы `project-x` / `project_x` сохранены внутри архивных манифестов, путей, конфигураций и точных выходов для воспроизводимости. Ссылки на старые файлы продолжают работать.

Рейтинг показывает уже измеренные конфигурации детерминированного парсера и адаптированной интеграции native Vision v1. Новое название не превращает эти результаты в отдельный тест приватного форка. Модели, версии, числа, ошибки, контрольные суммы и время прежних испытаний сохранены.

Это адаптация, а не полностью независимая реализация: история исходного проекта и сведения об авторстве сохранены в приватном репозитории. Переименование само по себе не улучшает точность извлечения.
