# Где скачать и установить инструменты

В [рейтинге](TOOL-LEADERBOARD-RU.md) название инструмента ведёт на его репозиторий с установкой или Releases. Последний столбец «Манифест» ведёт на сохранённые результаты: это разные ссылки.

Одна программа может занимать несколько строк рейтинга из-за разных моделей, режимов или устройств. Эти ссылки ведут к продуктам; точная испытанная версия, параметры и изменения адаптера остаются в манифестах.

| Решение | Скачать / установить | Доступ и соответствие испытанию |
|---|---|---|
| catalog-to-json | [Публичный репозиторий и установка](https://github.com/megamen32/catalog-to-json) | FastAgent/CLI/Agent Plugin 1.0; отдельные версии и модели в рейтинге, без наследования оценок поздними выпусками. |
| Catalog Vision Backend | [Репозиторий и установка](https://github.com/megamen32/catalog-vision-backend) | Приватное решение, доступ по запросу. Планируем предоставлять бесплатно. |
| Docling | [Репозиторий и установка](https://github.com/docling-project/docling) | Открытый репозиторий; установка по README. |
| MinerU | [Репозиторий и установка](https://github.com/opendatalab/MinerU) | Открытый репозиторий; basic/standard/advanced и CPU/GPU/Metal — разные конфигурации. |
| gmft | [Репозиторий и установка](https://github.com/conjuncts/gmft) | Открытый репозиторий; установка по README. |
| img2table | [Репозиторий и установка](https://github.com/xavctn/img2table) | Открытый репозиторий; установка по README. |
| Marker | [Репозиторий и установка](https://github.com/datalab-to/marker) | Открытый репозиторий; зависимости и условия моделей — в документации проекта. |
| Camelot | [Репозиторий и установка](https://github.com/camelot-dev/camelot) | Открытый репозиторий; lattice и stream — разные режимы. |
| Tabula Java | [Репозиторий и установка](https://github.com/tabulapdf/tabula-java) | Открытый репозиторий; готовые JAR — в Releases. |
| PyMuPDF4LLM | [Репозиторий и установка](https://github.com/pymupdf/pymupdf4llm) | Открытый репозиторий; установка по README. |
| Unstructured | [Репозиторий и установка](https://github.com/Unstructured-IO/unstructured) | Открытый репозиторий; здесь измерен локальный hi-res. |

| pdf-mcp | [Репозиторий и установка](https://github.com/jztan/pdf-mcp) | Открытый репозиторий; установка MCP по README. |

| Xberg | [Репозиторий и установка](https://github.com/xberg-io/xberg) | Открытый репозиторий; готовые платформенные пакеты — в Releases. |

У Catalog Vision Backend нет публичного ZIP исходников. Для доступа напишите [владельцу в GitHub](https://github.com/megamen32), указав свой GitHub-логин. До приглашения приватная ссылка может показывать 404. [Подробнее о компоненте и происхождении оценок](CATALOG-VISION-BACKEND.md).
