# What the scores mean

A matching number alone is not an engineering match. Each fact requires the correct source-scoped product, one unambiguous physical parameter, applicable unit/condition/bound, value and explicit cell state. The same predicates consume canonical JSON from every project.

- **Engineering facts:** 500 assertions across all 15 cases. There are 320 table-body cells on three innovation pages and 15 selected assertions on each of the other twelve pages. Some selected assertions cover multiple source rows; they still count as one assertion.
- **Literal cells:** exact NFC/whitespace-normalized table bodies, including source spelling and numeric typography. Reported separately from numeric decimal comma/dot equivalence.
- **Headers:** selected literal assertions on field labels, groups, units and qualifiers. Engineering glyph aliases are diagnostic rather than blanket Latin/Cyrillic correction of product codes or `СЗ`.
- **Blank and merged cells:** reviewed table bodies retain true source blanks and repeated shared source values. `unknown` never equals `blank`. The schema tests shared value association, not all geometric span boundaries.
- **Figures:** selected required labels and selected source-absent declared labels. Positive figure assertions consume declared labels, including combined labels on the same figure; prose saying a label is missing is not evidence it exists. Explicit dash glyph variants are normalized for selected forbidden labels. This does not detect all hallucinations or establish diagram geometry.

Hierarchical group + leaf + qualifier may jointly express one field. Composite headers that collapse independent parameters or voltage conditions cannot be repaired by the grader. A missing/empty physical unit may inherit a unique literal unit from the matched field/group. A conflicting explicit unit fails. Source-unspecified units in selected ARM/IZ annotations are unscored. Original mixed `мм²/мм` columns must retain the printed combination. Source `B2` on page 78 has unit **м**; the benchmark preserves the source rather than correcting a suspected typo.

The three body-table fixtures grade product rows by source identity within the corresponding table, then find a unique semantic field. Literal tables still preserve row/column order. Duplicate identities or multiple plausible columns fail as ambiguous. Other cases use published source-specific row scopes, conductor/part/manufacturer restrictions and condition predicates. A source model copied into an unrelated comment cannot supply identity evidence.

Reports retain failures, unavailable assertions, changed artifacts and malformed candidates. `percent_on_attempted_cases` includes unavailable facts from attempted cases in its denominator. A deadline-stopped matrix reports incomplete; it is not a complete dataset result. Family macro percentages reduce domination by densely annotated pages but do not replace per-case details. Compare identical case sets, stages, dataset versions and grader digests; do not mix repetitions or rank differently configured projects as a universal model comparison.

`all_verified_checks_passed` means only the frozen assertions passed. No score certifies full prose, every source note, all figure dimensions/tolerances, complete merge geometry, every invention, or a production-ready Excel catalogue. Full-page ground truth is explicitly false in each case and score.

Historical evaluations used an earlier private grader. This public version adds stricter checks for collapsed headers, identity evidence, figure-token boundaries and label denials. Regrade the same immutable outputs before comparing numbers between versions.

## Grader v0.2.1: drawing token boundaries

Drawing matching keeps separators between independent labels and accepts ordinary punctuation after a dimension. It still rejects a longer number or a decimal continuation (for example `476` does not match `476,5`) and requires the original charge group, execution and view association. This fixes false misses in retained page-26 agent outputs; annotations and expected values are unchanged. Frozen v0.2.0 measurements remain historical results. Regrading saved output with v0.2.1 is a new grader cohort, not another model execution.
